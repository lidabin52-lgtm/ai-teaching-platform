## 1. 平台简介

本平台是一款面向编程学习者的在线技能闯关系统，通过游戏化的学习方式帮助你掌握编程技能。平台提供以下核心功能：

- **技能闯关**：丰富的编程关卡，从基础到进阶，循序渐进提升编程能力
- **段位系统**：青铜到王者的段位晋升机制，让学习更有动力
- **AI导师**：智能AI助手随时为你答疑解惑，提供个性化学习建议
- **实时代码评测**：提交代码后即时获得运行结果和反馈
- **学习进度追踪**：可视化展示你的学习轨迹和能力成长

## 2. 注册与登录

### 2.1 注册新账号

1. 打开平台首页，点击右上角的 **「注册」** 按钮
2. 在注册页面填写以下信息：
   - **用户名**：2-20个字符，支持中英文、数字
   - **邮箱**：请使用有效的邮箱地址，用于找回密码
   - **密码**：至少8位，建议包含字母、数字和特殊字符
   - **确认密码**：再次输入密码
   - **身份选择**：选择 **「学生」**
3. 阅读并同意用户协议
4. 点击 **「立即注册」** 完成注册
5. 注册成功后系统会自动跳转到登录页面

### 2.2 登录账号

1. 在首页点击右上角的 **「登录」** 按钮
2. 输入注册时使用的用户名或邮箱
3. 输入密码
4. 点击 **「登录」** 即可进入平台

### 2.3 找回密码

1. 在登录页面点击 **「忘记密码」**
2. 输入注册时使用的邮箱地址
3. 查收邮箱中的重置密码链接
4. 通过链接设置新密码

## 3. 技能闯关功能详解

### 3.1 关卡总览

登录后进入首页，你可以看到 **技能树** 界面，展示所有可挑战的关卡。关卡按技能模块分类，每个模块包含多个难度递增的关卡。

### 3.2 如何选择关卡

1. **浏览关卡列表**：在技能树中选择你感兴趣的技能模块（如 Python 基础、数据结构、算法等）
2. **查看关卡信息**：点击任意关卡卡片，可查看以下信息：
   - 关卡名称与描述
   - 难度等级（简单/中等/困难）
   - 预计完成时间
   - 通过率
   - 所需前置技能
3. **解锁条件**：部分关卡需要先完成前置关卡才能解锁，已解锁的关卡会高亮显示
4. **开始挑战**：点击 **「开始挑战」** 按钮进入关卡答题界面

### 3.3 代码编辑器使用

进入关卡后，页面下方会显示 **在线代码编辑器**，主要功能如下：

| 功能 | 说明 |
|------|------|
| **代码编辑区** | 在此编写你的代码，支持语法高亮 |
| **自动补全** | 输入代码时按 `Tab` 键或 `Ctrl+Space` 触发智能补全 |
| **字体大小调节** | 通过编辑器右上角的按钮放大/缩小字体 |
| **主题切换** | 支持亮色/暗色编辑器主题 |
| **重置代码** | 点击重置按钮可恢复到初始代码模板 |
| **全屏模式** | 点击全屏按钮进入沉浸式编码模式 |

### 3.4 提交审判

1. **编写代码**：在编辑器中完成代码编写
2. **提交代码**：点击编辑器下方的 **「提交」** 按钮（或使用快捷键 `Ctrl+Enter`）
3. **等待评测**：系统会自动运行你的代码并进行多组测试用例的验证
4. **查看结果**：评测完成后会弹出 **审判结果弹窗**，显示详细的评测信息

### 3.5 查看结果

审判结果弹窗包含以下信息：

- **评测状态**：
  - **通过（Accepted）**：所有测试用例均通过，恭喜通关！
  - **未通过（Wrong Answer）**：部分或全部测试用例未通过
  - **运行错误（Runtime Error）**：代码执行过程中发生错误
  - **超时（Time Limit Exceeded）**：代码运行时间超过限制
- **测试用例详情**：展示每个测试用例的输入、期望输出和你的实际输出
- **执行时间与内存消耗**：显示代码的运行性能指标
- **优化建议**：AI会根据你的代码给出改进建议

> **提示**：未通过的关卡可以无限次重新挑战，每次提交都会记录你的最佳成绩。

## 4. 段位系统说明

平台采用游戏化的段位晋升机制，根据你的综合表现进行段位评定。

### 4.1 段位等级

| 段位 | 图标 | 所需积分 | 说明 |
|------|------|----------|------|
| **青铜** | Bronze | 0 - 199 | 入门阶段，适合编程初学者 |
| **白银** | Silver | 200 - 499 | 基础扎实，能独立完成简单编程任务 |
| **黄金** | Gold | 500 - 999 | 技能熟练，具备解决中等难度问题的能力 |
| **钻石** | Diamond | 1000 - 1999 | 能力出众，能应对复杂编程挑战 |
| **王者** | King | 2000+ | 编程高手，具备全面的编程素养 |

### 4.2 积分获取方式

- **通关关卡**：根据关卡难度获得对应积分
  - 简单关卡：+10 积分
  - 中等关卡：+25 积分
  - 困难关卡：+50 积分
- **首次通关奖励**：首次通过关卡额外获得 +5 积分
- **连续通关加成**：连续通过关卡可获得额外加成
- **代码质量评分**：代码运行效率高、写法优雅可获得额外加分

### 4.3 段位展示

- 你的当前段位会显示在 **个人主页** 和 **导航栏** 上
- 段位图标会根据等级变化而升级
- 达到新段位时系统会发送 **晋升通知**

## 5. AI导师使用方法

### 5.1 打开AI导师

- 在任意页面点击右下角的 **「AI导师」** 浮动按钮
- AI导师面板会从右侧滑出，你可以随时与它对话

### 5.2 AI导师功能

AI导师提供以下智能辅助功能：

1. **代码答疑**
   - 描述你遇到的问题，AI导师会给出详细的解答
   - 支持粘贴代码片段进行分析

2. **思路引导**
   - 当你对某道关卡没有思路时，可以向AI导师请求提示
   - AI会逐步引导你思考，而不是直接给出答案

3. **代码审查**
   - 提交代码后，AI导师会自动分析你的代码
   - 指出可优化的地方并给出改进建议

4. **知识拓展**
   - 关卡相关的知识点讲解
   - 推荐相关的学习资源和练习

### 5.3 使用技巧

- **提问要具体**：描述清楚你的问题、期望的结果和当前的报错信息
- **善用上下文**：AI导师能感知你当前所在的关卡，可以直接问"这道题怎么做"
- **请求提示而非答案**：说"给我一个提示"比"告诉我答案"更有助于学习
- **追问深入**：对AI的回答可以继续追问，获得更深入的解释

## 6. 学习进度查看

### 6.1 个人主页

点击导航栏中的 **「个人中心」** 进入个人主页，可以查看：

- **基本信息**：用户名、段位、注册时间
- **学习统计**：已通关关卡数、总积分、学习天数
- **能力分布**：各技能模块的掌握程度可视化展示

### 6.2 学习轨迹

在个人主页中可以查看你的 **学习轨迹**：

- **日历热力图**：类似GitHub的贡献图，展示每天的学习活跃度
- **通关时间线**：按时间顺序展示你的通关记录
- **能力成长曲线**：展示你的编程能力随时间的变化趋势

### 6.3 成就系统

平台内置了丰富的成就徽章，完成特定目标即可解锁：

- **初出茅庐**：通过第一个关卡
- **连续作战**：连续7天登录学习
- **速度之星**：在30秒内通过一个关卡
- **全能选手**：在每个技能模块中至少通过一个关卡
- 更多成就等你探索...

## 7. 常见问题FAQ

### Q1：忘记密码怎么办？

在登录页面点击「忘记密码」，通过注册邮箱重置密码。如果邮箱也无法访问，请联系教师或管理员协助处理。

### Q2：代码提交后一直显示评测中怎么办？

可能是服务器负载较高，请耐心等待1-2分钟。如果超过5分钟仍未出结果，请刷新页面后重新提交。

### Q3：我的代码在本地运行正常，但提交后报错怎么办？

常见原因包括：
- 输入输出格式与题目要求不一致
- 未处理边界情况（如空输入、最大值等）
- 使用了题目不允许的第三方库
- 代码中存在硬编码的路径或文件名

建议仔细阅读题目要求，检查输入输出格式，并使用AI导师辅助排查。

### Q4：段位会下降吗？

段位不会下降。你的段位只会上升或保持不变，积分也是只增不减的。

### Q5：可以重复挑战已通过的关卡吗？

可以。已通过的关卡可以随时重新挑战，但重复通关不会额外获得积分。系统会记录你的最佳成绩。

### Q6：AI导师给出的答案一定是正确的吗？

AI导师基于大语言模型提供辅助，大多数情况下能给出正确的指导，但偶尔可能出现不准确的情况。建议结合自己的判断，遇到不确定的内容可以查阅官方文档或咨询老师。

### Q7：如何联系老师？

你可以通过平台内的消息功能联系你的任课教师，或在课堂上直接向老师提问。

### Q8：支持哪些编程语言？

目前平台主要支持 **Python** 语言，后续将陆续增加对 JavaScript、Java、C++ 等语言的支持。
