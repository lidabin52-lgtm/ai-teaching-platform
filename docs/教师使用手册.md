## 1. 平台简介

本平台是一款面向编程教学的在线技能闯关系统，为教师提供全面的学情分析和教学管理工具。教师端核心功能包括：

- **学情分析仪表盘**：实时掌握班级整体学习情况和每位学生的学习状态
- **学生详情查看**：深入了解学生的能力分布和学习轨迹
- **关卡管理**：创建、编辑和管理编程关卡，灵活定制教学内容
- **数据导出**：支持导出学情数据，便于教学分析和存档
- **AI辅助教学**：利用AI导师功能，为学生提供个性化辅导

## 2. 教师账号登录

### 2.1 登录方式

1. 打开平台首页，点击右上角的 **「登录」** 按钮
2. 输入管理员分配的教师账号（用户名或邮箱）
3. 输入密码
4. 点击 **「登录」** 即可进入教师端界面

### 2.2 首次登录

首次登录后建议完成以下操作：

1. **修改密码**：进入个人设置，修改初始密码为强密码
2. **完善个人信息**：填写姓名、所授课程、联系方式等
3. **查看班级列表**：确认已关联的教学班级信息

### 2.3 账号权限说明

教师账号具有以下权限：

| 权限 | 说明 |
|------|------|
| 查看学情数据 | 可查看所教班级及学生的全部学习数据 |
| 管理关卡 | 可创建、编辑、发布和下线关卡 |
| 查看学生详情 | 可查看学生的能力雷达图、学习轨迹等详细信息 |
| 导出数据 | 可导出班级和学生的学情数据报表 |
| AI导师配置 | 可配置AI导师的辅导策略和回答范围 |

> **注意**：教师账号仅能查看所关联班级的学生数据，无法跨班级查看。

## 3. 学情分析仪表盘使用

登录后默认进入 **学情分析仪表盘** 页面，该页面以数据可视化的方式展示班级整体学习情况。

### 3.1 仪表盘概览

仪表盘顶部展示以下核心指标卡片：

| 指标 | 说明 |
|------|------|
| **班级总人数** | 当前班级中的学生总数 |
| **今日活跃人数** | 当天至少完成一次学习操作的学生人数 |
| **平均通关率** | 班级所有学生已通过关卡占已挑战关卡的平均比例 |
| **平均段位** | 班级学生的段位分布情况 |
| **本周新增通关** | 本周内班级学生新通过的关卡总数 |
| **待关注学生** | 学习进度明显落后或长时间未登录的学生数量 |

### 3.2 学习活跃度趋势图

- **图表类型**：折线图
- **时间维度**：支持按天/周/月查看
- **数据内容**：展示班级每日/每周/每月的活跃学生人数变化趋势
- **用途**：帮助教师了解学生的学习节奏，识别学习高峰和低谷期

### 3.3 关卡通过率分布

- **图表类型**：柱状图
- **数据内容**：展示每个关卡的班级通过率
- **颜色标识**：
  - 绿色：通过率 >= 80%（掌握良好）
  - 黄色：通过率 50%-80%（需要关注）
  - 红色：通过率 < 50%（教学难点）
- **用途**：快速定位教学难点，针对性地调整教学计划

### 3.4 段位分布图

- **图表类型**：饼图/环形图
- **数据内容**：展示班级学生在各段位的人数分布
- **用途**：了解班级整体水平，评估教学效果

### 3.5 学生排行榜

- **排序方式**：默认按积分降序排列，支持按通关数、活跃度等维度排序
- **展示信息**：学生姓名、段位、积分、已通关数、最近活跃时间
- **用途**：了解班级中的学习标兵和需要帮助的学生

### 3.6 数据筛选与导出

- **时间筛选**：可选择查看特定时间段内的学情数据
- **班级切换**：如管理多个班级，可通过下拉菜单切换
- **数据导出**：点击右上角的 **「导出报表」** 按钮，可将当前仪表盘数据导出为 Excel 或 PDF 格式

## 4. 学生详情查看

在仪表盘或学生列表中点击任意学生姓名，即可进入该学生的 **详情页面**。

### 4.1 学生基本信息

页面顶部展示学生的基本信息：

- 姓名、用户名、注册时间
- 当前段位与积分
- 累计学习天数、最近登录时间
- 已通关关卡数 / 总关卡数

### 4.2 能力雷达图

- **图表类型**：雷达图（蛛网图）
- **评估维度**：平台根据学生闯关表现，从以下维度评估能力：
  - **基础语法**：对编程语言基础知识的掌握程度
  - **逻辑思维**：算法设计和逻辑推理能力
  - **代码规范**：代码风格、命名规范和可读性
  - **调试能力**：发现和修复代码错误的能力
  - **效率优化**：代码运行效率和空间复杂度优化能力
  - **综合应用**：综合运用多种知识解决复杂问题的能力
- **评分范围**：每个维度 0-100 分
- **用途**：全面了解学生的能力优势和薄弱环节，便于因材施教

### 4.3 学习轨迹

- **时间线视图**：按时间倒序展示学生的学习活动记录，包括：
  - 通关记录（通过/未通过）
  - 代码提交次数和每次提交的结果
  - AI导师使用记录
  - 登录记录
- **活跃度日历**：以热力图形式展示学生的每日学习活跃度
- **能力成长曲线**：展示学生各维度能力随时间的变化趋势
- **用途**：追踪学生的学习过程，识别学习瓶颈和进步节点

### 4.4 关卡完成详情

- **已通过关卡列表**：展示学生已通过的所有关卡，包括通过时间、提交次数、代码运行时间
- **未通过关卡列表**：展示学生尝试过但未通过的关卡，包括尝试次数、常见错误类型
- **代码查看**：教师可查看学生通过关卡的代码实现，了解学生的编程思路

### 4.5 教学建议

系统会基于学生的学情数据自动生成教学建议：

- 针对薄弱技能的练习推荐
- 适合当前水平的关卡推荐
- 学习节奏调整建议

## 5. 关卡管理说明

### 5.1 关卡列表

点击导航栏中的 **「关卡管理」** 进入关卡管理页面，展示所有已创建的关卡。

- **列表字段**：关卡名称、所属模块、难度等级、通过率、状态（已发布/草稿/已下线）
- **搜索与筛选**：支持按名称搜索、按模块和难度筛选
- **排序**：支持按创建时间、通过率、难度等排序

### 5.2 创建新关卡

点击 **「创建关卡」** 按钮，按以下步骤完成关卡创建：

#### 第一步：基本信息

- **关卡名称**：简洁明了地描述关卡内容
- **所属模块**：选择关卡所属的技能模块（如 Python 基础、循环结构、函数等）
- **难度等级**：选择简单/中等/困难
- **预计完成时间**：预估学生完成该关卡所需时间
- **前置关卡**：设置需要先完成的前置关卡（可选）

#### 第二步：题目描述

- **题目背景**：描述关卡的故事背景或实际应用场景
- **任务要求**：清晰列出学生需要完成的具体任务
- **输入格式**：说明输入数据的格式和范围
- **输出格式**：说明期望的输出格式
- **样例**：提供至少一组输入输出样例

#### 第三步：测试用例

- **公开测试用例**：学生可见的测试用例，用于帮助学生理解题目
- **隐藏测试用例**：学生不可见，用于最终评测，确保代码的通用性
- **边界测试用例**：测试边界条件（如空输入、最大值、最小值等）

#### 第四步：代码模板

- **初始代码**：为学生提供代码起始模板
- **预设代码**：系统预设的辅助代码（学生不可修改）
- **参考答案**：教师编写的参考解答（仅教师可见）

#### 第五步：配置与发布

- **时间限制**：设置代码运行的最大时间限制（单位：秒）
- **内存限制**：设置代码运行的最大内存限制（单位：MB）
- **积分设置**：设置通关可获得的积分
- **发布状态**：选择保存为草稿或直接发布

### 5.3 编辑与下线关卡

- **编辑关卡**：在关卡列表中点击 **「编辑」**，可修改关卡的任何内容
- **下线关卡**：点击 **「下线」**，关卡将从学生的技能树中隐藏，但已通过的记录保留
- **删除关卡**：草稿状态的关卡可以删除，已发布的关卡需先下线再删除

### 5.4 关卡数据统计

每个关卡都附带详细的数据统计：

- **通过率**：班级通过率和个人通过率
- **平均提交次数**：学生通过该关卡的平均尝试次数
- **平均完成时间**：从开始挑战到通过的平均耗时
- **常见错误类型**：统计学生最常见的错误类型分布

## 6. 常见问题FAQ

### Q1：如何创建教师账号？

教师账号由平台管理员统一创建和分配。如需开通教师账号，请联系平台管理员并提供姓名、所授课程和邮箱地址。

### Q2：可以同时管理多个班级吗？

可以。教师账号可以关联多个教学班级，在仪表盘顶部通过班级切换下拉菜单进行切换。

### Q3：学情数据多久更新一次？

学情数据为 **实时更新**，学生的每次提交和操作都会即时反映在仪表盘上。页面会自动刷新，也可以手动刷新获取最新数据。

### Q4：能否查看学生的代码实现？

可以。在学生详情页面的「关卡完成详情」部分，教师可以查看学生通过每个关卡时提交的代码。

### Q5：如何调整关卡的难度和积分？

进入关卡管理页面，点击对应关卡的「编辑」按钮，即可修改难度等级和积分设置。修改后即时生效。

### Q6：学生反馈AI导师回答不准确怎么办？

教师可以在AI导师配置中调整辅导策略，增加对特定知识点的约束。同时建议引导学生多方验证AI给出的信息。

### Q7：导出的报表包含哪些数据？

导出的报表包含班级整体统计数据和每位学生的详细数据，包括通关记录、积分、段位、活跃度等。支持 Excel 和 PDF 两种格式。

### Q8：如何重置学生的关卡进度？

目前暂不支持单个学生重置。如确有需要，请联系平台管理员处理。

### Q9：能否自定义技能模块？

可以。在关卡管理中可以创建新的技能模块，也可以对已有模块进行重命名和排序调整。

### Q10：平台支持哪些浏览器的教师端？

推荐使用最新版本的 **Chrome**、**Edge** 或 **Firefox** 浏览器访问教师端。不建议使用 IE 浏览器。
