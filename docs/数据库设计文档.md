## 1. 系统概述

本系统是一个 **AI驱动的Web前端技能闯关学习平台**，核心功能包括：

- **技能闯关系统**: 学生通过完成不同段位（青铜/白银/黄金/钻石/王者）的编程关卡来学习前端技术
- **AI智能审判**: 学生提交代码后，AI自动从正确性、代码质量、最佳实践、创新性四个维度进行评分
- **AI导师对话**: 学生可以与AI导师进行实时对话，获取学习指导和代码反馈
- **知识库系统**: 为AI导师提供结构化的知识文档，支持语义检索
- **学情分析**: 追踪学生的学习进度、得分统计和连续打卡记录
- **班级管理**: 教师可创建班级、管理学生、查看学情

数据库共包含 **9张表**，其中8张业务表和1张关联表。

### 2.2 关系汇总

| 关系 | 类型 | 说明 |
|------|------|------|
| users -> challenges | 一对多 | 一个用户(教师)可创建多个关卡 |
| users -> submissions | 一对多 | 一个学生可提交多次闯关代码 |
| users -> ai_conversations | 一对多 | 一个学生可发起多个AI对话 |
| users -> student_progress | 一对一 | 一个学生对应一条学习进度记录 |
| users -> classes | 一对多 | 一个教师(班主任)可管理多个班级 |
| users -> knowledge_base | 一对多 | 一个用户可创建多篇知识文档 |
| users <-> classes | 多对多 | 学生通过 class_students 关联表加入多个班级 |
| challenges -> submissions | 一对多 | 一个关卡可被多次提交 |
| challenges -> ai_conversations | 一对多 | 一个关卡可关联多个AI对话 |
| ai_conversations -> ai_messages | 一对多 | 一个对话包含多条消息 |

## 3. 数据表详细设计

### 3.1 users - 用户表

> 存储学生和教师信息，是系统的核心用户实体。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INT | PK, AUTO_INCREMENT | 用户ID，主键自增 |
| `username` | VARCHAR(50) | UNIQUE, NOT NULL | 用户名，唯一标识 |
| `password` | VARCHAR(255) | NOT NULL | 密码，BCrypt加密存储 |
| `email` | VARCHAR(100) | UNIQUE, NOT NULL | 邮箱地址 |
| `nickname` | VARCHAR(50) | DEFAULT '' | 昵称 |
| `avatar` | VARCHAR(500) | DEFAULT '' | 头像URL |
| `role` | ENUM | DEFAULT 'student' | 用户角色：student / teacher / admin |
| `status` | SMALLINT | DEFAULT 1 | 状态：1=正常，0=禁用 |
| `last_login_at` | DATETIME | NULLABLE | 最后登录时间 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**:
- `PRIMARY KEY` on `id`
- `UNIQUE INDEX` on `username`
- `UNIQUE INDEX` on `email`

---

### 3.2 challenges - 关卡表

> 技能闯关系统的核心数据表，存储所有关卡信息、评分标准和AI审判配置。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INT | PK, AUTO_INCREMENT | 关卡ID，主键自增 |
| `title` | VARCHAR(200) | NOT NULL | 关卡标题 |
| `description` | TEXT | NOT NULL | 需求描述，Markdown格式 |
| `difficulty` | ENUM | NOT NULL, DEFAULT 'bronze' | 段位：bronze / silver / gold / diamond / king |
| `order_num` | INT | DEFAULT 0 | 同段位内的排序号 |
| `category` | VARCHAR(50) | NOT NULL | 分类（如 HTML、CSS、JavaScript、综合） |
| `tags` | JSON | NULLABLE | 标签数组 |
| `starter_code` | TEXT | NULLABLE | 初始代码模板 |
| `language` | VARCHAR(20) | DEFAULT 'html' | 编程语言 |
| `scoring_criteria` | JSON | NOT NULL | 评分标准JSON，如 `{"correctness":30, "code_quality":25, "best_practice":25, "creativity":20}` |
| `ai_prompt` | TEXT | NULLABLE | AI审判系统提示词 |
| `expected_output` | TEXT | NULLABLE | 期望输出描述 |
| `time_limit` | INT | DEFAULT 0 | 时间限制（分钟），0表示不限时 |
| `hint_count` | INT | DEFAULT 3 | 可用提示次数 |
| `unlock_requirement` | JSON | NULLABLE | 解锁条件JSON，如 `{"prev_challenge_id":1}` |
| `status` | SMALLINT | DEFAULT 1 | 状态：1=上架，0=下架 |
| `created_by` | INT | FK -> users.id | 创建者（教师）ID |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**:
- `PRIMARY KEY` on `id`
- `INDEX idx_difficulty_order` on (`difficulty`, `order_num`) -- 复合索引，加速按段位排序查询
- `INDEX idx_category` on (`category`) -- 按分类筛选
- `FOREIGN KEY` on `created_by` -> `users.id`

---

### 3.3 submissions - 提交记录表

> 存储学生闯关提交的代码和AI审判结果，包含四维度评分详情。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INT | PK, AUTO_INCREMENT | 提交ID，主键自增 |
| `user_id` | INT | FK -> users.id, NOT NULL | 学生ID |
| `challenge_id` | INT | FK -> challenges.id, NOT NULL | 关卡ID |
| `code` | TEXT | NOT NULL | 提交的代码内容 |
| `code_hash` | VARCHAR(64) | NULLABLE | 代码哈希值，用于查重 |
| `ai_feedback` | TEXT | NULLABLE | AI评语（详细版） |
| `ai_summary` | VARCHAR(500) | NULLABLE | AI评语摘要 |
| `total_score` | INT | NULLABLE | 总分（0-100） |
| `stars` | SMALLINT | NULLABLE | 获得星数（0-3） |
| `score_correctness` | SMALLINT | NULLABLE | 正确性得分 |
| `score_code_quality` | SMALLINT | NULLABLE | 代码质量得分 |
| `score_best_practice` | SMALLINT | NULLABLE | 最佳实践得分 |
| `score_creativity` | SMALLINT | NULLABLE | 创新性得分 |
| `scoring_details` | JSON | NULLABLE | 评分详情JSON |
| `status` | ENUM | DEFAULT 'pending' | 状态：pending / judging / completed / failed |
| `attempt_number` | INT | DEFAULT 1 | 第几次尝试 |
| `time_spent` | INT | NULLABLE | 耗时（秒） |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 提交时间 |
| `judged_at` | DATETIME | NULLABLE | AI审判完成时间 |

**索引**:
- `PRIMARY KEY` on `id`
- `INDEX idx_user_challenge` on (`user_id`, `challenge_id`) -- 复合索引，查询某学生某关卡的提交记录
- `INDEX idx_challenge_status` on (`challenge_id`, `status`) -- 复合索引，查询某关卡的提交统计
- `FOREIGN KEY` on `user_id` -> `users.id`
- `FOREIGN KEY` on `challenge_id` -> `challenges.id`

---

### 3.4 ai_conversations - AI对话表

> 学生与AI导师的对话会话，每个会话可关联一个关卡。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INT | PK, AUTO_INCREMENT | 对话ID，主键自增 |
| `conversation_no` | VARCHAR(64) | UNIQUE, NOT NULL | 对话编号，唯一标识 |
| `user_id` | INT | FK -> users.id, NOT NULL | 学生ID |
| `challenge_id` | INT | FK -> challenges.id, NULLABLE | 关联的关卡ID |
| `title` | VARCHAR(200) | DEFAULT '' | 对话标题 |
| `message_count` | INT | DEFAULT 0 | 消息数量 |
| `knowledge_refs` | JSON | NULLABLE | 引用的知识库文档ID列表 |
| `status` | SMALLINT | DEFAULT 1 | 状态：1=正常，0=已归档 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**:
- `PRIMARY KEY` on `id`
- `UNIQUE INDEX` on `conversation_no`
- `INDEX idx_user` on (`user_id`) -- 查询某学生的对话列表
- `INDEX idx_updated_at` on (`updated_at`) -- 按更新时间排序
- `FOREIGN KEY` on `user_id` -> `users.id`
- `FOREIGN KEY` on `challenge_id` -> `challenges.id`

### 3.5 ai_messages - AI消息表

> 对话中的具体消息内容，支持文本、代码、图片三种类型。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INT | PK, AUTO_INCREMENT | 消息ID，主键自增 |
| `conversation_id` | INT | FK -> ai_conversations.id, NOT NULL | 所属对话ID |
| `role` | ENUM | NOT NULL | 角色：user / assistant / system |
| `content` | TEXT | NOT NULL | 消息内容 |
| `content_type` | ENUM | DEFAULT 'text' | 内容类型：text / code / image |
| `code_language` | VARCHAR(20) | NULLABLE | 代码语言（当 content_type=code 时） |
| `referenced_code` | TEXT | NULLABLE | 引用的学生代码片段 |
| `tokens_used` | INT | NULLABLE | 消耗的token数 |
| `response_time_ms` | INT | NULLABLE | 响应耗时（毫秒） |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 发送时间 |

**索引**:
- `PRIMARY KEY` on `id`
- `INDEX idx_conversation` on (`conversation_id`) -- 查询某对话的所有消息
- `FOREIGN KEY` on `conversation_id` -> `ai_conversations.id`

### 3.9 class_students - 班级学生关联表

> 班级与学生的多对多关联中间表。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INT | PK, AUTO_INCREMENT | 关联ID，主键自增 |
| `class_id` | INT | FK -> classes.id, NOT NULL | 班级ID |
| `student_id` | INT | FK -> users.id, NOT NULL | 学生ID |
| `joined_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 加入时间 |

**索引**:
- `PRIMARY KEY` on `id`
- `UNIQUE CONSTRAINT uk_class_student` on (`class_id`, `student_id`) -- 防止重复加入
- `FOREIGN KEY` on `class_id` -> `classes.id`
- `FOREIGN KEY` on `student_id` -> `users.id`

## 4. 索引设计

### 4.1 索引总览

| 表名 | 索引名 | 索引类型 | 字段 | 用途说明 |
|------|--------|----------|------|----------|
| **users** | PRIMARY | 主键索引 | `id` | 主键查询 |
| users | username (UNIQUE) | 唯一索引 | `username` | 登录查询 |
| users | email (UNIQUE) | 唯一索引 | `email` | 邮箱唯一性校验 |
| **challenges** | PRIMARY | 主键索引 | `id` | 主键查询 |
| challenges | idx_difficulty_order | 复合索引 | `difficulty`, `order_num` | 按段位排序查询关卡列表 |
| challenges | idx_category | 普通索引 | `category` | 按分类筛选关卡 |
| **submissions** | PRIMARY | 主键索引 | `id` | 主键查询 |
| submissions | idx_user_challenge | 复合索引 | `user_id`, `challenge_id` | 查询某学生某关卡的提交记录 |
| submissions | idx_challenge_status | 复合索引 | `challenge_id`, `status` | 统计某关卡的提交状态分布 |
| **ai_conversations** | PRIMARY | 主键索引 | `id` | 主键查询 |
| ai_conversations | conversation_no (UNIQUE) | 唯一索引 | `conversation_no` | 对话编号唯一性 |
| ai_conversations | idx_user | 普通索引 | `user_id` | 查询学生的对话列表 |
| ai_conversations | idx_updated_at | 普通索引 | `updated_at` | 按更新时间排序 |
| **ai_messages** | PRIMARY | 主键索引 | `id` | 主键查询 |
| ai_messages | idx_conversation | 普通索引 | `conversation_id` | 查询对话的所有消息 |
| **knowledge_base** | PRIMARY | 主键索引 | `id` | 主键查询 |
| knowledge_base | idx_category | 普通索引 | `category` | 按分类筛选知识文档 |
| knowledge_base | idx_difficulty | 普通索引 | `difficulty` | 按难度筛选知识文档 |
| **student_progress** | PRIMARY | 主键索引 | `id` | 主键查询 |
| student_progress | uk_user | 唯一约束 | `user_id` | 每个学生仅一条进度记录 |
| **classes** | PRIMARY | 主键索引 | `id` | 主键查询 |
| classes | invite_code (UNIQUE) | 唯一索引 | `invite_code` | 邀请码唯一性 |
| classes | idx_teacher | 普通索引 | `teacher_id` | 查询教师管理的班级 |
| **class_students** | PRIMARY | 主键索引 | `id` | 主键查询 |
| class_students | uk_class_student | 唯一约束 | `class_id`, `student_id` | 防止学生重复加入班级 |

### 4.2 索引设计说明

1. **复合索引 `idx_difficulty_order`**: 关卡列表页最常用的查询是"按段位筛选 + 排序"，该复合索引完美覆盖此场景，避免文件排序。
2. **复合索引 `idx_user_challenge`**: 查询学生是否已提交某关卡、获取最佳成绩等场景，`(user_id, challenge_id)` 的复合索引可高效定位。
3. **复合索引 `idx_challenge_status`**: 教师查看某关卡的通过率、提交统计时，`(challenge_id, status)` 可快速聚合。
4. **唯一约束 `uk_class_student`**: 防止同一学生重复加入同一班级，保证数据一致性。

## 6. 关键业务流程的数据流向

### 6.1 学生闯关提交流程

```
学生选择关卡 (challenges)
    |
    v
编写代码并提交
    |
    +---> 创建提交记录 (submissions)
    |     - status = 'pending'
    |     - code = 学生提交的代码
    |     - attempt_number = 递增
    |     - time_spent = 计时统计
    |
    v
AI审判系统处理
    |
    +---> 更新提交记录 (submissions)
    |     - status = 'judging' -> 'completed'
    |     - total_score, stars = AI评分结果
    |     - score_correctness / score_code_quality / score_best_practice / score_creativity
    |     - ai_feedback, ai_summary = AI评语
    |     - scoring_details = 评分详情JSON
    |     - judged_at = 审判完成时间
    |
    v
更新学生进度 (student_progress)
    |
    +---> 对应段位 completed + 1
    +---> total_submissions + 1
    +---> total_stars += 本次获得星数
    +---> avg_score = 重新计算
    +---> current_streak / longest_streak = 更新打卡
    +---> last_submission_at = 当前时间
```

### 6.2 AI导师对话流程

```
学生发起对话
    |
    +---> 创建对话会话 (ai_conversations)
    |     - conversation_no = 生成唯一编号
    |     - user_id = 当前学生
    |     - challenge_id = 关联关卡（可选）
    |
    v
学生发送消息
    |
    +---> 创建消息记录 (ai_messages)
    |     - role = 'user'
    |     - content = 学生的问题
    |     - content_type = 'text' / 'code'
    |
    v
系统检索知识库 (knowledge_base)
    |
    +---> 根据 category / tags / difficulty 匹配
    +---> 更新 knowledge_refs 引用列表
    +---> knowledge_base.reference_count + 1
    |
    v
AI生成回复
    |
    +---> 创建消息记录 (ai_messages)
    |     - role = 'assistant'
    |     - content = AI回复内容
    |     - referenced_code = 引用的代码片段（如有）
    |     - tokens_used = token消耗
    |     - response_time_ms = 响应耗时
    |
    v
更新对话统计 (ai_conversations)
    |
    +---> message_count + 1
    +---> updated_at = 当前时间
```

### 6.3 班级管理流程

```
教师创建班级
    |
    +---> 创建班级记录 (classes)
    |     - name = 班级名称
    |     - invite_code = 生成邀请码
    |     - teacher_id = 当前教师
    |
    v
学生通过邀请码加入
    |
    +---> 创建关联记录 (class_students)
    |     - class_id = 班级ID
    |     - student_id = 学生ID
    |     - joined_at = 加入时间
    |
    v
教师查看班级学情
    |
    +---> 查询 class_students 获取班级学生列表
    +---> 关联 student_progress 获取每个学生的进度数据
    +---> 关联 submissions 获取提交详情
```
